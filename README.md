# FilmRadar plugins for Claude Code

```sh
claude plugin marketplace add thefilmradar/claude-plugins
claude plugin install filmlab@thefilmradar
```

Then sign in: `/mcp` → `plugin:filmlab:filmlab` → Authenticate.

| Plugin | What it does |
|---|---|
| `filmlab` | FilmLab MCP server plus two skills that take a brief to a finished, editable film and hand timelines to Resolve, Premiere or Final Cut. |

This repository is a read-only mirror. It is generated from FilmRadar's main
repository, so changes made here are overwritten; pull requests are not
merged. FilmLab: https://lab.thefilmradar.com
